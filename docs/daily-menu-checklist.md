# 手动验收清单（分支 app-v1）

版本：2026-09-05（成品图 + 卡片改版 + 多关键词搜索 + 采购清单优化）
历史：2026-06-24 版（日视图 + 弹窗勾选 + 统一清单）已被本版取代。

## 准备

- [ ] `npm run dev` 启动后打开应用，本地有旧数据时确认迁移行为（食谱/菜单/采购不丢，`image`、`checkedAt` 字段兼容）。

## 菜单计划（单日视图）

- [ ] 默认聚焦今天，日期头显示「9月5日 周六」格式；前一天/后一天/回到今天可用。
- [ ] 卡片：左侧 56px 成品图（无图显示占位图标），名称下只显示「N 食材 · M 调味料」数量，不显示分类和做法。
- [ ] 「⋮」更多菜单默认隐藏，点开显示「改到（日期选择）」和删除按钮；改日期后卡片从当天消失并提示目标日期。
- [ ] 按住卡片左侧手柄可拖动排序（鼠标和触屏都要试），松手后顺序持久化（刷新不丢）。
- [ ] 搜索提示词为「想吃什么就告诉我，别客气！」；空格分隔多关键词（如「番茄 鸡蛋」）全部命中才显示；候选最多 8 个且不含当天已安排。
- [ ] 点选候选后立即弹出食材勾选弹窗；勾选缺少的食材「加入已选」写入采购清单。

## 食谱库

- [ ] 卡片左侧 84px 成品图或占位图标；名称 + 食材名称摘要。
- [ ] 折叠状态没有任何操作按钮；轻点卡片展开做法，「添加到菜单 / 编辑 / 删除」三个图标按钮与做法一起显示。
- [ ] 「添加到菜单」弹出「今天/明天」；选择后该食谱出现在对应日期，并弹出食材勾选弹窗。
- [ ] 搜索支持空格分隔多关键词；分类筛选按钮正常。
- [ ] 编辑页：可上传/更换/移除成品图（大图会被自动压缩）；保存后图片在卡片和计划页都显示。

## 采购清单

- [ ] 顶栏「手动添加 / 批量删除 / 复制清单」三个按钮同一行（含 390px 手机宽度），无换行溢出。
- [ ] 未勾选项按 分类 → 添加时间 在前；勾选后该 item 沉底，最新勾选的永远排最后（刷新后顺序保持）。
- [ ] 数量+单位与名称同一行（如「西兰花 300g」）；弹窗内同样。
- [ ] 「批量删除」在有勾选项时可用，confirm 后一次性删除全部已勾选；无勾选项时置灰。
- [ ] 「复制清单」粘贴结果为 `- 名称 数量单位`，无勾选标记、无分类后缀。

## 数据与导入

- [ ] 「数据 → 导入」选择 `recipes.json`（107/163 带图）后，食谱库出现成品图；导入前有替换确认弹窗。
- [ ] 「数据 → 导出」的 JSON 再导入后图片不丢失。
- [ ] 手机端（APK）导入后应用不卡顿、无存储配额报错。

- [ ] `npm run build` 通过。
