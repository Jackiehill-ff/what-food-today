# 菜单计划改版 · 手动验收清单

版本：2026-06-24（日视图 + 弹窗勾选 + 统一清单）

## 准备

- [ ] `npm run dev` 启动后打开应用，本地有旧数据时确认迁移行为。

## 首页（今天的菜单）

- [ ] 打开应用默认显示"今天的菜单"。
- [ ] 今天有安排时，按添加顺序展示当天食谱，含食材和做法。
- [ ] 今天无安排时显示空态 + "去安排今天的菜单"按钮，点击跳转到菜单计划页的今天。

## 菜单计划（单日视图）

- [ ] 菜单计划页默认聚焦今天，顶部日期头显示"6月25日 周四"格式。
- [ ] "前一天 / 后一天"可切换日期，"回到今天"按钮可跳回今天。
- [ ] 同一天安排多道菜时按添加顺序排列，新菜排在后面。
- [ ] 每道菜右侧有移除按钮，可移出当天菜单。
- [ ] 搜索候选最多显示 8 个；已在当天的食谱不会重复出现在候选中。

## 弹窗勾选（备菜清单）

- [ ] 在搜索候选中点选一个食谱后，立即弹出食材勾选弹窗。
- [ ] 弹窗列出该食谱全部食材（含数量/单位），默认不勾选。
- [ ] "全选"可一键勾选/取消全部；"加入已选 (N)"只把勾选项写入采购清单，来源显示食谱名。
- [ ] 弹窗可点关闭或点击遮罩关闭；未勾选任何食材时"加入已选"不可用。
- [ ] 食谱没有食材时弹窗显示提示，不报错。
- [ ] 加入后计划页出现"已加入 N 项到采购清单"提示。

## 采购清单（统一清单）

- [ ] 采购清单页只有一个统一清单，不再按天/日期分类。
- [ ] 清单按 分类 → 未勾选优先 → 添加时间 排序。
- [ ] 手动添加不再有日期选择；添加的项来源显示"手动添加"。
- [ ] "复制清单"复制的是统一清单文本（含勾选状态）。

## 旧数据迁移

- [ ] 老用户菜单计划数据不丢失：同一天"早餐→午餐→晚餐"顺序迁移后保留为列表顺序。
- [ ] 老用户采购清单项不丢失。
- [ ] 老用户食谱不丢失，旧字段（name/steps/notes/seasonings）正确迁移。
- [ ] 未登录状态所有功能可用。

## 构建

- [ ] `npm run build` 通过。
