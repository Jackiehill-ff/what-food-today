# 手动验收清单（分支 app-v1）

版本：2026-09-17（分段式导入 + 编辑页列表化 + 箭头统一 + 新图标 + 我的页统计）
历史：2026-09-05 版（成品图 + 卡片改版）与 2026-06-24 版（日视图 + 弹窗勾选）已被本版取代。

## 准备

- [ ] `npm run dev` 启动后打开应用，本地有旧数据时确认迁移行为（食谱/菜单/采购不丢，`image`、`checkedAt`、`unit` 字段兼容）。

## 菜单计划（单日视图）

- [ ] 默认聚焦今天；前一天/后一天/回到今天可用。
- [ ] 卡片：左侧 56px 成品图（无图显示占位图标），名称下只显示「N 食材 · M 调味料」数量。
- [ ] 右侧为无框向下箭头（无方框边框）；点开后箭头变向上，上方显示完整做法（保留换行、超高可滚动），底部同一行为「修改时间」日期选择和「删除」按钮。
- [ ] 按住卡片左侧手柄可拖动排序（鼠标和触屏都要试），松手后顺序持久化。
- [ ] 搜索提示词为「想吃什么就告诉我，别客气！」；空格分隔多关键词全部命中才显示；候选最多 8 个且不含当天已安排。
- [ ] 点选候选后立即弹出食材勾选弹窗：顺序为**先食材、后调味料**（与编辑页一致，不应乱序）；勾选缺少的食材「加入已选」写入采购清单。

## 食谱库

- [ ] 卡片左侧 84px 成品图或占位图标；名称 + 食材名称摘要；展开箭头位于卡片最右侧。
- [ ] 折叠状态没有任何操作按钮；轻点卡片展开做法与「添加到菜单 / 编辑 / 删除」。
- [ ] 「添加到菜单」弹出「今天/明天」；选择后出现在对应日期并弹出勾选弹窗。
- [ ] 搜索支持空格分隔多关键词；分类筛选按钮正常。

## 编辑食谱页

- [ ] 食材 / 调味料以紧凑列表显示：每行「名称 + 用量」摘要（空数量不显示「无」）+ 编辑/删除按钮。
- [ ] 点编辑弹窗：名称 / 数量（占位「无」）/ 分类 / 上移下移 / 删除 / 完成，修改即时生效；弹窗内没有「单位」栏。
- [ ] 点「添加」直接弹出空编辑框，完成后新项出现在对应分类列表末尾。
- [ ] 在弹窗中改「分类」可将项在食材/调味料之间移动，弹窗自动关闭且不再自己弹出。
- [ ] 已有成品图时右侧只有「移除图片」（无「换一张」）；移除后可重新上传，大图自动压缩。

## 导入中心

- [ ] 粘贴文本框占位文字为「把你喜欢的食谱复制过来吧～」。
- [ ] 分段式食谱（小标题 + 「- 」行 + emoji 步骤 + 💡Tips，如北非花椰菜沙拉）解析出标题、食材（含用量）、做法+小贴士，无需手动补全。
- [ ] 传统「食材：/调味料：/做法：」格式解析正常；盐/酱油等自动归入调味料。
- [ ] 导入预览每行可编辑名称和数量；保存到食谱库后用量保留。

## 采购清单

- [ ] 顶栏「手动添加 / 批量删除 / 复制清单」同一行（含 390px 手机宽度）。
- [ ] 未勾选项按 分类 → 添加时间 在前；勾选后沉底，最新勾选排最后。
- [ ] 数量+单位与名称同一行；「批量删除」一次性删除全部已勾选；「复制清单」粘贴为 `- 名称 数量单位`。

## 我的

- [ ] 品牌卡下显示三列统计：食谱 / 已安排 / 采购项（与侧栏一致，390px 下三列不溢出）。
- [ ] 无反馈面板；账号与数据面板正常（导出/导入）。

## 图标与导航

- [ ] APK 桌面图标为黄色碗新图标；网页标签页 favicon 同图。
- [ ] 导航顺序：菜单计划 → 食谱库 → 采购清单 → 导入中心 → 我的。

## 构建与数据

- [ ] `npm run build` 通过。
- [ ] 「数据 → 导出」的 JSON 再导入后图片与字段不丢失。
- [ ] 手机端（APK）导入后应用不卡顿、无存储配额报错。
