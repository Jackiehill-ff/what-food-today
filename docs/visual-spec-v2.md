## 6. 动效规范（新增）

**原则：快、轻、可关闭。忙碌用户对等待和卡顿零容忍，动效只用于"确认操作已生效"，不做装饰性动画。**

| Token | 值 | 用途 |
|---|---|---|
| `--dur-fast` | `120ms` | hover / focus 颜色过渡 |
| `--dur-base` | `180ms` | 按钮按压、卡片选中、tab 切换 |
| `--dur-slow` | `240ms` | modal / 抽屉进出 |
| `--ease-out` | `cubic-bezier(.2,.8,.3,1)` | 统一缓出曲线 |

具体约定：

- 按钮 `:active` 统一 `transform: scale(.97)` + `--dur-fast`，给"点到了"的即时反馈。
- 卡片选中（加入今日菜单）：背景色过渡 + 边框变 `--border-selected`，180ms；**不加位移/弹跳**，避免列表抖动。
- Modal / 抽屉：`opacity` + `translateY(8px)` 组合，240ms。
- 「一键生成清单」完成后，清单区首屏做一次 200ms 的淡入即可，不做逐条 stagger。
- **必须支持 `prefers-reduced-motion: reduce`**：命中时所有动效降级为 0ms 瞬时切换。

## 7. 无障碍基线（新增）

| 规则 | 标准 |
|---|---|
| 正文文字对比度 | ≥ 4.5:1（本次已修复 muted-2） |
| 大字号（≥20px/750）与图标 | ≥ 3:1（本次已修复 muted-3） |
| 键盘 focus 可见 | 所有可交互元素必须有 `--focus-ring`，禁止 `outline: none` 裸奔 |
| 触控目标 | 移动端 ≥ 44×44px；桌面端主按钮高度 40px（本次由 38px 上调） |
| 色彩不作为唯一信息载体 | 如"已勾选"除绿色外必须有 `Check` 图标 |
